# Similarweb CSV 仓库分流与使用入口 / Repository triage and usage entry points

本页是**候选工作台**，不是公开案例目录。297 条 GitHub 落地页先归一为 245 个 URL 仓库根；按 GitHub 数字 ID 再合并 3 个更名/转移别名，得到 237 个可读的独立仓库身份和 5 个本轮不可读的根。Jev 对 240 次可读仓库请求的缩略 README、项目描述和顶层文件名进行了类型与场景分流；分数是模型判断，不是来源真实性、项目实际效果或发布资格。

This is a **review queue**, not a published-case index. The 297 landing-page rows first normalize to 245 URL roots. Numeric GitHub IDs merge three rename/transfer aliases, leaving 237 readable repository identities and five unavailable roots. Jev classified shortened README/metadata/file names in 240 successful calls, including those aliases. Its scores are model outputs, not proof of source identity, effectiveness or admission.

“是什么”栏保留仓库作者的简短 GitHub 描述作为线索；“怎么用”只指向固定版本 README，不代表我们已核验命令或运行结果。**只有“已发布”条目链接本库的双语详解**，其中写明输入、判断、输出、复现步骤和限制。其余项目继续按 PRD 的证据门槛逐项审阅，不能从模型标签自动升为 `verified`。

The “what” column is an attributed GitHub description lead. The “how” link opens a pinned README; its instructions are not yet reviewed or run. **Only published rows link to full bilingual case explanations.** All others require pinned implementation, identity, rights and reproduction review under the PRD.
