# Jev Arena / Jev Arena 评论标注对比

## 中文

### 项目简介

一个将同批评论交给 Jev 和另一模型标注的比较工具，支持 CSV/Excel 导入、回放和离线报告。它来自用户提供的 GitHub 落地页线索，未在本轮网站本地目录中匹配到同仓库项目。

### Jev 的具体作用

Jev 后端通过 OpenRouter 的 Decisions 接口请求 `typesafe/jev-1.13`，对每条评论回答相关性、情感、意图等类型化问题，并返回概率或分数。宿主程序转换分数和整理报告；展示用的证据短句由宿主从原文截取，不是 Jev 生成。

### 如何复现

按固定版本 README 准备 Node.js 22+，安装依赖并配置自己的 OpenRouter 与对照模型凭据，从默认合成评论的小批次开始。回放与离线报告无需再次调用模型；实时对比会消耗所配置提供方的额度。

### 证据与限制

已核对仓库身份、固定 README、Jev 后端模型 ID 与请求、运行器及 MIT 许可证；未执行比较或复测。作者公布的耗时、费用和准确率只对应其数据与配置，且准确率复核采用 AI 参考而非人工金标准。本库不把它们作为独立性能结论。演示评论不属于代码的 MIT 许可范围。

## English

### Overview

A comparison tool that labels the same comments with Jev and another model, with CSV/Excel import, replay and offline reports. It came from the supplied GitHub landing-page lead and did not match a same-repository entry in the local website catalog reviewed here.

### Jev's specific role

The Jev backend requests `typesafe/jev-1.13` through OpenRouter Decisions, asking typed relevance, sentiment and intent questions for each comment and returning probabilities or scores. Host code converts scores and builds reports. Displayed evidence snippets are mechanically extracted from source comments by the host, not generated by Jev.

### Reproduction

Follow the pinned README with Node.js 22+, install dependencies and configure your own OpenRouter and comparison-model credentials. Start with the small default synthetic-comment set. Replay and offline reporting do not call the models again; live comparisons consume provider quota.

### Evidence and limitations

Repository identity, pinned README, Jev model ID and request path, runner and MIT license were reviewed; the comparison was not run or reproduced here. Author-reported time, cost and accuracy apply only to that dataset and configuration, and the accuracy review used an AI reference rather than a human gold standard. They are not independent performance findings of this catalog. Demo comments are outside the code's MIT license.
